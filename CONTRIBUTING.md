# Contributing to Serverless Telegram Bot Boilerplate

Thank you for your interest in contributing! This document provides guidelines for contributing to the project.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/yourusername/serverless-bot-boilerplate.git`
3. Create a branch: `git checkout -b feature/your-feature-name`
4. Make your changes
5. Run tests: `npm test`
6. Run linting: `npm run lint`
7. Commit your changes: `git commit -m "Add your feature"`
8. Push to your fork: `git push origin feature/your-feature-name`
9. Create a Pull Request

## Code Style

- Use TypeScript for all new code
- Follow the existing code style (enforced by ESLint)
- Add types for all functions and variables
- Write descriptive commit messages
- Add comments for complex logic

## Testing

- Write tests for new features
- Ensure all tests pass before submitting PR
- Aim for good test coverage
- Test both success and error cases

## Pull Request Process

1. Update the README.md with details of changes if needed
2. Update the CHANGELOG.md with your changes
3. Ensure all tests pass
4. Request review from maintainers

## Areas for Contribution

- Adding support for new AI providers
- Improving error handling
- Adding new dialog states/flows
- Improving documentation
- Adding more tests
- Performance optimizations
- Bug fixes

## Questions?

Feel free to open an issue for any questions or suggestions!
